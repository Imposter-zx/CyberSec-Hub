# Security Policy

## Supported Versions

We release security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | Yes |

---

## Reporting a Vulnerability

CyberSec Hub takes security seriously. If you discover a security vulnerability within the platform:

1. Do **NOT** disclose the vulnerability publicly in issues or discussions.
2. Email security details to `security@cybersechub.org` (or submit a Private Vulnerability Report on GitHub).
3. Include:
   - Detailed description of the vulnerability.
   - Steps to reproduce the issue.
   - Potential impact.
4. We will acknowledge receipt within 48 hours and work with you on a coordinated fix.
